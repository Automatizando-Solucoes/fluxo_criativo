# Copy de página Hermes

Leia e aplique `adapters/hermes/SOURCE-POLICY.md` antes de consultar qualquer fonte Claude.

1. Resolva `copy.page` no registry e exija `product_slug`, `page_type` e conteúdo.
2. Use o produto ativo e leia somente os artefatos locais necessários: perfil, pesquisa e identidade do consumidor, quando existirem.
3. Consulte `paginas`, `revisora`, elementos literários e Manual da Copy apenas como fontes metodológicas.
4. Aplique o gate comum de revisão e persista somente a copy aprovada no produto.

Não execute command Claude, provider, deploy ou publicação.
