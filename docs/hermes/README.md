# Hermes Adapter

Esta documentação descreve a ponte dry-run entre o core neutro e Hermes. Ela não instala Hermes, não inicia gateway, não cria cron real e não chama providers.

O estado de negócio continua em `meus-produtos/`; `HERMES.md` é o contexto operacional próprio do runtime. Consulte os contratos em `core/` antes de evoluir wrappers, delegates, cron ou integrações.
