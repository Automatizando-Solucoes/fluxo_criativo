# Biblioteca neutra de metodologia

`agents/` contém metodologia e políticas compartilhadas, sem autoridade de runtime. `core/` contém contratos de negócio executáveis. `adapters/` integra cada runtime com os mesmos contratos.

- `AGENTS.md` é o entrypoint do Codex.
- `CLAUDE.md` é o entrypoint do Claude.
- `HERMES.md` é o entrypoint do Hermes.

Uma fonte desta pasta pode ensinar critérios, frameworks, fórmulas, templates e revisão. Ela não pode executar shell, provider, cron, publicação, deploy ou ler segredos.
